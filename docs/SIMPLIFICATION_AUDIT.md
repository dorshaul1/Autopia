# Simplification audit (Phase 68)

The journey everything serves: open or create a product, say what to build, see what the team is doing, step in only when needed, look at the product, review the result, carry on.

Before: 11 places in the header, a separate Studio with 5 more, 6 settings pages reached a different way, tabs inside Memory, and back, forward and focus controls on top.
After: 4 places, 5 tools under More, and Settings.

| Surface | Call | Why |
|---|---|---|
| Overview | KEEP, IMPROVE | The one page for a product: what it is, what's happening, what needs you, where to see it |
| Mission Control | MERGE into Overview | Same work as Overview's lists. The work list is now the Overview |
| Office | KEEP | What makes Autopia itself |
| Preview | KEEP | The real product |
| Deliveries | KEEP as Results | Same screen, plainer name |
| Team conversation | KEEP | How you ask for everything. One place for it |
| Ask or find (⌘K) | KEEP | Finds anything; replaces several routes |
| Time and cost | KEEP in More | Removed, then put back at the user's request. Per-teammate timeline, time and money. The rule learned: stats people enjoy earn their place even if they aren't on the main path |
| Files, Checks (was Operations), Memory, Logs | RELOCATE to More | Useful now and then, not all the time |
| Brief | RELOCATE to a link on Overview | Read occasionally; not a destination |
| Memory's 5 tabs | MERGE into one page | Decisions first, the rest folded away. Lessons still reach the team, they just have no tab |
| Memory's Context use and stat cards | REMOVE | Diagnostics for building Autopia, not for using it |
| Studio | REMOVE | Team lives in the Office, decisions in the conversation and tray, Skills in Settings |
| Studio: How the team performs | REMOVE, can come back | Cross-product stats. Open question to the user |
| Studio: Team and Operations | REMOVE | Every product's state is on Home and in the rail |
| Decision Center page | REMOVE | The cards stay in the conversation and the tray; a third list added nothing |
| Skills | RELOCATE to Settings | Configuration |
| Per-product model picker | REMOVE | One choice in Settings. A hidden override would be worse than none |
| Priority controls | REMOVE | Rarely used. Autopia still orders work by dependencies |
| Product details panel | REMOVE | Repeated the Overview; Show in Finder and Pause are in the product menu |
| Back and forward, focus mode, conversation-only mode | REMOVE | Few places means little to go back through. Settings has its own Back |
| Filter by teammate, Recent changes feed | REMOVE | Short lists don't need filters; the conversation and Logs carry the record |
| Tell the team button in the status bar | REMOVE | The composer and ⌘K do this |
| Permissions, notifications, status bar, tray | KEEP | Control and honesty |

Data: nothing in the database was changed or deleted. A window remembering a removed page lands on the Overview or Home.
